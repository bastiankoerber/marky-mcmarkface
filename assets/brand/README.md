# Brand assets

The master Marky McMarkface icon was generated with OpenAI's built-in image-generation tool and
then resized locally for the application shell, browser favicons, Apple touch icon, and web app
manifest. The icon contains no third-party trademarks or source artwork.

Design prompt: a minimal folded-paper capital M with two tiny ink-dot eyes and a muted red
proofreader pencil stroke, rendered as a warm, editorial, vector-friendly app icon without text.

`app-icon-master.png` is the original source. Derive new sizes from it rather than scaling one of
the smaller browser assets.

`app-icon.icns` is the macOS application icon and `app-icon.ico` is ready for a future Windows
package. The numbered PNG files are used by the browser manifest and desktop build pipeline.
